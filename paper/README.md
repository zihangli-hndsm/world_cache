# Paper draft

This directory contains the compile-checked paper and supplement. From this
directory:

```bash
make
```

The figures used by the TeX sources are the local snapshots in `paper/figures/`.
The review-date regenerated copies are under
`outputs/reports/20260923_review_figures/`. Numerical tables are generated by
`scripts/generate_supplementary_tables.py` from the supplied experiment
snapshot.

Before circulating the draft, run:

```bash
make verify
```

The clean ViT-G correspondence protocol for an individual cached pair is:

```bash
PYTHONPATH=./scripts \
  conda run -n worldcache python \
  scripts/evaluate_3rscan_spatial_consensus.py \
  --pair-run outputs/runs/<pair-run> \
  --annotation-root /path/to/3rscan \
  --output-dir outputs/runs/reproduce_pair \
  --model-size giant --layers 2 20 40 --top-k 20 \
  --threshold 0.10 --iterations 1500 \
  --save-query-diagnostics --save-candidate-set-audit
```

The evaluator builds candidates from RGB tokens and native RGB-D geometry; the
hidden scan transform and annotation labels are used only for scoring. The
The external inputs are the FCGF checkpoint and the 3RScan annotation/data root,
as well as the DINOv2 weights and frame archives; they are not bundled.

The following audits are reproducible from the checked-in scripts:

- learned geometry control: `scripts/evaluate_3rscan_fcgf_baseline.py`;
- finite-sample risk audit: `scripts/evaluate_risk_controlled_calibration.py`;
- candidate availability: `scripts/aggregate_candidate_set_audit.py`;
- paired scale uncertainty: `scripts/audit_backbone_scaleup.py`;
- RANSAC seed sensitivity: `scripts/aggregate_seed_sweep.py`;
- downstream label transfer: `scripts/summarize_baseline_label_transfer.py`.

Date-stamped manifest, bundle, and external-validation paths are intentionally
not stated as released facts in this review-date snapshot. Generate a fresh
manifest and bundle only after the final split, provenance, and figures have
been frozen.
